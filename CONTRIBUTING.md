# Přispívání do projektu

Děkujeme za váš zájem přispět do Thermostat Control Card! 🎉

## Jak přispět

### Hlášení chyb

1. Zkontrolujte, zda už chyba nebyla nahlášena v [Issues](../../issues)
2. Pokud ne, vytvořte nový issue s podrobným popisem
3. Použijte template pro bug report
4. Přidejte screenshoty a konfiguraci pokud je to možné

### Návrhy funkcí

1. Zkontrolujte [Issues](../../issues) zda návrh už neexistuje
2. Vytvořte nový issue s popisem funkce
3. Použijte template pro feature request
4. Popište use case a očekávané chování

### Pull Requests

1. Forkněte si repozitář
2. Vytvořte novou branch (`git checkout -b feature/AmazingFeature`)
3. Commitněte změny (`git commit -m 'Add some AmazingFeature'`)
4. Pushněte do branch (`git push origin feature/AmazingFeature`)
5. Otevřete Pull Request

## Coding Standards

### JavaScript

- Používejte ES6+ syntax
- Komentujte složitější logiku
- Dodržujte existující styl kódu
- Používejte `const` a `let` místo `var`

### CSS

- Používejte kebab-case pro třídy
- Organizujte CSS logicky
- Používejte CSS custom properties kde je to možné
- Přidávejte komentáře pro komplexní layouty

### Commity

- Pište jasné commit messages
- Používejte přítomný čas ("Add feature" ne "Added feature")
- Pište stručně ale výstižně

## Testování

Před odesláním PR otestujte:

1. Kartu v Home Assistant
2. Různé konfigurace
3. Různé climate entity
4. Responzivnost na různých zařízeních
5. Různé browsery pokud je to možné

## Otázky?

Pokud máte otázky, neváhejte:
- Otevřít issue s otázkou
- Začít diskuzi v GitHub Discussions

Děkujeme za váš čas! ❤️
